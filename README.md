# 🦀 Rustlings

Small exercises to get you used to reading and writing Rust code - Recommended in parallel to reading the official Rust book 📚️

## ✅ Topics

### 1️⃣ 기초 문법 (Foundations)
- [x] **Introduction**: 환경 설정 및 시작 (`intro1`, `intro2`)
- [x] **Variables**: 변수 선언, 가변성, 섀도잉
- [x] **Functions**: 파라미터와 반환값 처리
- [x] **Conditionals**: `if`, `else` 기반 제어문
- [x] **Primitive Types**: 스칼라 타입, 배열, 튜플, 슬라이스

### 2️⃣ 소유권과 데이터 구조 (Ownership & Data)
- [x] **Move Semantics**: 소유권 이전, 복사, 참조 규칙
- [x] **Strings**: `&str`과 `String`의 활용
- [x] **Structs & Enums**: 구조체와 열거형, 패턴 매칭
- [x] **Modules**: 프로젝트 구조화 및 가시성 제어
- [x] **Collections**: `Vec`, `HashMap` 활용 및 퀴즈 풀이

### 3️⃣ 에러 처리와 제너릭 (Robustness)
- [x] **Options & Errors**: `Option`, `Result`를 이용한 안전한 에러 핸들링
- [x] **Generics**: 코드 재사용성을 위한 제너릭 타입
- [x] **Traits**: 인터페이스 정의와 트레이트 바운드 구현

### 4️⃣ 고급 개념 (Advanced)
- [x] **Lifetimes**: 참조자의 유효 기간 명시 및 관리
- [x] **Iterators**: 선언적 루프 처리와 어댑터 활용
- [x] **Smart Pointers**: `Box`, `Rc`, `Arc`, `Cow` 메모리 관리
- [x] **Threads**: 멀티 스레딩 및 동시성 제어
- [x] **Macros**: 선언적 매크로 작성법

### 5️⃣ 마무리 (Tooling & Conversion)
- [x] **Tests**: 유닛 테스트 작성 및 검증
- [x] **Clippy**: Rust 린터를 활용한 코드 최적화
- [x] **Type Conversion**: `as`, `From/Into`, `TryFrom/TryInto`, `AsRef/AsMut`
